# Checklist

## send_order_result 格式验证
- [ ] 成功场景包含 `**💡 排查建议**` 区域，内容为"无"
- [ ] 失败场景正确从 error 字段提取错误码（正则匹配）
- [ ] 错误信息超过50字符时截断并添加"..."
- [ ] 市价单（order_type == "MARKET"）价格显示"市价"
- [ ] 失败场景订单ID显示"None"
- [ ] 成功场景订单ID显示实际订单号

## 状态图标映射验证
- [ ] NEW 状态显示 ✅ 已挂单
- [ ] FILLED 状态显示 ✅ 已成交
- [ ] PARTIALLY_FILLED 状态显示 ⚠️ 部分成交
- [ ] 失败状态显示 ❌ 下单失败

## 错误码知识库验证
- [ ] -1021 返回时间漂移相关3条建议
- [ ] -1109 返回API Key环境不匹配相关3条建议
- [ ] -2015 返回权限不足相关3条建议
- [ ] -2019 返回保证金不足相关3条建议
- [ ] -2022 返回价格超出范围相关3条建议
- [ ] 未知错误码返回通用建议3条

## 格式一致性验证
- [ ] 所有通知方法包含统一的状态引用块（> **状态**: ...）
- [ ] 所有通知方法包含统一的页脚（--- + 节点 + 时间）
- [ ] env_info 正确显示在页脚中
