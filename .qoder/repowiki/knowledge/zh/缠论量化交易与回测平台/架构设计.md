- **前后端分离架构**：`trading_system` 作为后端核心，通过 FastAPI 提供 RESTful API（`/api/backtest`, `/api/signal`），`frontend` 作为独立 React 应用消费这些接口进行可视化展示。
- **统一入口与配置**：根目录 `main.py` 负责启动后端服务并初始化数据库连接，`.env` 文件统一管理数据库、交易所 API 密钥等敏感配置，确保开发与生产环境隔离。
- **模块化策略与执行层**：`trading_system` 内部采用分层设计，`strategies` 模块封装缠论及多因子逻辑，`binance` 模块处理交易所交互，`backtest` 模块提供历史数据回放，各层通过 `core/schemas` 定义的标准数据模型进行通信。
