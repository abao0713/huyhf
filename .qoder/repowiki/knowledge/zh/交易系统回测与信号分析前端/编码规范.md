- 所有 API 请求统一通过 `src/api.ts` 中的 `request` 辅助函数发起，该函数自动处理基础路径拼接和 HTTP 状态码错误抛出。
- 组件样式采用内联 style 与全局 CSS 类名（如 `.card`, `.btn-sm`, `.text-sm`）混合的方式，未使用 CSS Modules 或 styled-components。
- 表单状态管理采用局部 `useState` 对象存储所有字段，并通过通用的 `update` 函数进行更新，而非为每个字段创建独立的 state。
- 数值格式化逻辑（如千分位、百分比、小数位）直接在组件内部或通过简单的工具函数实现，未引入专门的格式化库。
